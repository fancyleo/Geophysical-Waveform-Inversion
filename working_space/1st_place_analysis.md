## 1. 第一名方案核心定位

- **不用 U-Net**：认为"这不是分割任务"——速度图像素与地震道**在空间上不对齐**，U-Net 跳跃连接（回传中间层特征）无意义。
- **用预训练 Vision Transformer**：本质是"把 ViT 当作分割式回归模型"。
- 训练成本：**4×RTX 5090，约 15 天**（评论区确认纯 Kaggle T4 资源几乎不可能进前排）。

## 2. 预处理（关键洞察）

| 做法 | 效果 |
|---|---|
| 原始 `(5,1000,70)` → 缩放 `(5,350,70)` | CV = 46.9 |
| **reshape 成 `(1,350,350)`**（把通道压进空间，变正方形图） | **CV 跳到 32.5** |
| 后期渐进增大图像尺寸（350→476→588→700，Top4 用 896） | 更稳、更省时地提升 |

> 正方形输入方便直接用预训练 ViT；逐级放大比重训大图更稳定高效。

## 3. 架构

- 预训练 ViT 编码器 + 解码器（encoder+decoder），CV 28。
- 消融发现 **EVA 相对 ViT 的提升主要来自 RoPE（旋转位置编码）** → 选
  `vit_small_patch14_reg4_dinov2.lvd142m` + RoPE，CV 降到 **26 MAE**。
- 输出头：**logits → sigmoid → 缩放到 (1500, 4500)**（物理速度范围）；loss = **MAE**。
- 更复杂头（UperNet / Mask2Former / ViT-Adapter / 融合头）**无帮助**。

## 4. 训练

- LR 1e-4 → cosine 至 1e-5；AdamW；MAE；**HFlip + TTA + EMA**。
- 47 万样本（44 万训练 / 3 万验证）；50 ep 到 26 仍**欠拟合** → 增大图像尺寸重训，共 **300 ep**。

## 5. 数据生成（最大杠杆）

1. **10× 增强扩充**：FiveCrop + 5×RandomAffine（对速度模型）→ 生成 **470 万**地震样本用于预训练（570 ep）。
2. **正演模拟提速**：公开完美正演从 10 张/分 → **>5000 张/分/GPU**（torch.compile + 5090）。
3. **Iterative Pseudo（迭代伪标签）**：每 epoch 后对 val+test（~9.5 万）预测速度 → **正演生成对应地震输入** → 加入下一 epoch 训练（自训练 + 物理一致）。
4. **Top4 家族聚焦**：新分数几乎全来自 `['CurveFault_B', 'CurveVel_B', 'Style_A', 'Style_B']` →
   删掉其余家族数据（>一半），训练专用模型，推理只替换这 4 家族预测 → CV 7.5 / 7.0/7.0。
5. 最终：896 尺寸 + Top4 模型集成 → **7.28 CV，6.9/6.9 LB**。

## 6. 没效果 / 没来得及试

- ❌ MAE/MIM 自监督预训练、标准增强、U-Net decoder、UperNet/Mask2Former/ViT-Adapter、更复杂头。
- 📌 未试 idea：预测速度 → 正演 → 与原地震求梯度，把「梯度 + 原地震 + 预测速度」喂给 refine 模型（物理引导精修）。

## 7. 评论区要点

- **第二名（Jeroen Cottaar）**：经典 FWI + 强先验，物理驱动（与第一名"学习先验"不同路线），单样本推理成本相近。
- **灵曜**：数据全部来自同一模拟器 → **"疯狂过拟合数据就是对的"**，解释了为何大增强 + 伪标签如此有效。

## 8. 对我们 UNet 方案的对照

| 维度 | 第一名 | 我们 |
|---|---|---|
| 架构 | 预训练 **ViT**（拒绝 U-Net） | **U-Net base32** |
| 数据规模 | **47 万** + 470 万增强 + 迭代伪标签 | **~1 万**（1/47 子集） |
| 输入 | reshape `(1,350,350)` 正方形 | `(5,1000,70)` abs+log1p |
| 增强/TTA | HFlip + TTA + EMA（有效） | 无增强；xflip TTA 在我们设置下无效 |
| 家族处理 | Top4 聚焦（含 CurveVel_B） | 难学家族加权（无效） |
| 计算 | 4×5090，15 天 | 单张 4090 |

**对我们最有价值的发现**：
1. **数据规模是决定性差异**（47 万 vs 1 万），且与我们"数据量 > 正则化"的结论一致 → **优先补齐全量数据重训**。
2. **U-Net 未必是对的架构**——第一名明确拒绝 U-Net 并改用预训练 ViT + RoPE（速度图与地震空间不对齐）。
3. **Iterative Pseudo（伪标签 + 物理一致正演）**是拉开差距的关键，可配合正演模拟无限造数据。
4. 他 Top4 聚焦含 `CurveVel_B`（我们最难家族）→ 难家族在**足够数据/正演支撑**下是可大幅提升的，只是我们小数据协议下看不出。
